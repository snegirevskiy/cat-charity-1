# Благотворительный фонд поддержки котиков QRKot

Сервис для управления благотворительным фондом, занимающимся поддержкой котиков. Приложение позволяет создавать целевые проекты для сбора средств и принимать пожертвования от пользователей.

## Функциональность

- Создание и управление целевыми благотворительными проектами
- Прием пожертвований от пользователей
- Автоматическое распределение пожертвований по активным проектам
- Отслеживание статуса проектов и пожертвований

## Технологии

- Python 3.8+
- FastAPI
- SQLAlchemy (асинхронный режим)
- SQLite
- Pydantic
